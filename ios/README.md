# Планер для iPhone

Планер устанавливается через AltStore Classic из файла `Planner-0.1.0-ios-altstore.ipa`. Нужен iPhone с iOS 17 или новее. AltStore подписывает файл при установке. Чтобы бесплатная подпись продлевалась в фоне, iPhone и Mac с запущенным AltServer должны регулярно находиться в одной сети Wi‑Fi. [Инструкция AltStore](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos)

Локальный план доступен с первого запуска. Чтобы подключить синхронизацию, нажмите «На iPhone», введите HTTPS-адрес своего сервера Планера и войдите в тот же аккаунт, что на компьютере. Все устройства с этим аккаунтом увидят его задачи, проекты и доступные общие пространства. Файлы, добавленные в серверном плане, также доступны на других устройствах при подключённом хранилище вложений. Кнопка «План на iPhone» возвращает к локальным делам.

Чтобы перенести накопившиеся локальные задачи и проекты, сохраните копию в «Файлы» из настроек локального плана, откройте личный план на сервере и выберите «Перенести из старого планера». Импорт пропускает записи с совпадающими идентификаторами. Вложения из локальных задач можно добавить к перенесённым задачам через редактор.

В голосовом окне доступна запись с микрофона. Чтобы разбирать записи и текст на устройстве, откройте «Подготовить голос» и загрузите модели Whisper и Qwen (около 2,7 ГБ). Для разбора нужен iPhone с 8 ГБ оперативной памяти и достаточно свободной памяти во время работы. После разбора можно поправить каждое дело перед добавлением. В подключённом плане сохраняются подтверждённые задачи. Записи остаются в приложении на iPhone.

## Сборка из исходников

Нужны Xcode с iOS SDK, Node.js 24, CMake и XcodeGen. Выполните из корня репозитория.

```sh
npm ci
bash ios/prepare-ios.sh
node ios/build-engines.mjs iphoneos iphonesimulator
```

Для запуска на симуляторе откройте `ios/Planner.xcodeproj` в Xcode. Задача **Actions → iPhone app** собирает приложение, проверяет локальный план на симуляторе и публикует артефакт `Planner-iPhone-AltStore` с IPA и SHA-256. Это сборка для подписи при установке через AltStore, на устройстве файл подписывает AltStore.
